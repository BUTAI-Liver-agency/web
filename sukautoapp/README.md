# BUTAI スカウト管理（PoC）

TikTokの募集動画にコメントした候補者を取り込み、DM文面を生成し、担当者が承認して手動送信し、
LINE到達までの歩留まりを計測するツール。

- 設計書: `docs/superpowers/specs/2026-09-13-tiktok-scout-crm-design.md`
- 実装計画: `docs/superpowers/plans/2026-09-13-tiktok-scout-crm-poc.md`
- DB初期設定: `docs/db-setup.md`
- 運用手順（スカウト担当者向け）: `docs/運用手順.md`

## 設計上の重要な前提

- **自動送信はしない。** 「承認」の実体は文面のクリップボードコピーとTikTokアプリの起動のみ。
  送信ボタンを押すのは人間。TikTokへ直接送信するコードは存在しない
- **対象は18歳以上のみ。** 年齢未確認の候補者は承認できない。
  ただしTikTokは年齢を公開しないため、確認は担当者の目視判断であり真正性は保証されない
- **文面にURLを含めない。** スパム判定回避のため、導線はTikTokプロフィール欄のリンクに統一する
- **AIが書くのは冒頭1〜2文のみ。** 事務所紹介・条件・導線はすべて固定文面
- **モバイル対応のWebページであり、インストール可能なPWAではない。** `manifest.webmanifest`
  はアイコンを持たず、Service Workerも実装していない。ホーム画面への追加やオフライン動作は
  現状できない。設計書ではPWAを構想として挙げているが、本PoCの実装範囲には含まれていない
- **再アプローチ（テンプレB）は今回のPoCでは使えない。** 送信キューは「まだ一度もDMを
  送っていない候補者（見込み）」しか扱わないため、テンプレAを送った後にテンプレBで
  再アプローチする導線は実装していない。ダッシュボードのテンプレート別の表でテンプレBの
  行が常にゼロになるのは、この仕様上の範囲であり不具合ではない

## 開発

```bash
npm install
cp .env.example .env   # 値を設定する
npm test               # 安全機構のテスト
npx vercel dev         # APIを含めた開発サーバー
```

### 環境変数

| 変数名 | 値 | 用途 |
|---|---|---|
| `VITE_SUPABASE_URL` | SupabaseのProject URL | フロントエンドからSupabaseへ接続する |
| `VITE_SUPABASE_ANON_KEY` | Supabaseのanon key | 同上 |
| `SUPABASE_URL` | SupabaseのProject URL | サーバーレス関数（`api/generate.ts`）が呼び出し元のログインを検証する |
| `SUPABASE_ANON_KEY` | Supabaseのanon key | 同上 |
| `ANTHROPIC_API_KEY` | Anthropicのキー | DM文面冒頭のAI生成 |

`SUPABASE_URL` / `SUPABASE_ANON_KEY`（`VITE_` が付かない2つ）は、AI生成エンドポイント（`/api/generate`）が「呼び出しているのはログイン済みの担当者か」を検証するために使う。**このエンドポイントは有料のAnthropicモデルを呼ぶため、認証を外してはならない。** 認証が外れると、URLさえ知っていれば誰でも事務所の費用でAPIを叩けてしまう（`api/generate.ts` の `isSignedIn` を参照）。デプロイ後も、この2変数が未設定のまま動いてしまわないか（＝認証チェックが機能しているか）を必ず確認すること。

### 既知の環境上の注意

この開発機は Node 20.18.1 で動作している。この版の Node では `jsdom` の最新系（テストが依存する `cssstyle` まわり）が正しく動かないため、`package.json` で `jsdom` を `^24` に固定し、`overrides` で `cssstyle` を `4.2.1` に固定している。

- 影響範囲は**テストのみ**。本番のアプリの挙動には影響しない
- Node を 20.19 以降（または22系）に上げれば、この固定は不要になる可能性が高い。将来Node を上げる際は、`jsdom` と `overrides.cssstyle` を外して `npm test` が通るか確認するとよい
