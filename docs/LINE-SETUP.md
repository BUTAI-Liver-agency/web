### ③ 経験者
ありがとうございます。所属についてのご相談ですね。
これまで利用した配信アプリと、今いちばん相談したいことを教えてください。所属条件やサポートについてご案内します。

## 設定時の確認

- 上記の3択を実際の選択肢として設定し、手動入力も受け付ける。自動応答とスタッフ返信を混同させない。
- 担当者の表示名と返信目安は、運用担当・稼働時間が決まり次第追加する。未確認の「24時間対応」等は記載しない。
- テストアカウントで友だち追加→3択→各返信→担当者対応の一連の動作を確認する。
- LPの3択は送信文作成補助。公式LINE内の自動応答とは独立している。

## 計測の定義

| 段階 | 計測方法 | 注意 |
|---|---|---|
| LP訪問 | 採用する解析サービスで集計 | 現在は未接続 |
| LINEボタンクリック | `butai:line_click`イベントのplacementを集計 | 現在はイベント通知のみで送信・保存なし |
| LINE友だち追加 | LINE側の追加経路別集計 | ボタンクリックから推定しない |
| 初回相談 | 実際に相談メッセージを送った人数 | 自動あいさつのみは含めない |
| 面談・所属・初配信 | 運用記録の実施日・確定日 | 実施した段階のみ計上 |
| 活動継続 | 初配信から30日経過した対象者を別集計 | 30日未経過者を分母に入れない |

`acquisition-weekly.csv`に週次で集計。単純な同週の件数比は流入元別の転換率ではない。正確な転換率には同一流入週のコホートを追跡する。個人の相談文・氏名を解析イベントに送らない。
